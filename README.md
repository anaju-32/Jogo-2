# Uma Praça para Todos

Jogo educativo interativo sobre acessibilidade, inclusão e autonomia.

## Arquivos

- `index.html`: estrutura das telas (nickname, boas-vindas, jogo e End Game).
- `style.css`: identidade visual, layout e responsividade.
- `script.js`: história, decisões, pontuação, rotas e finais.

## Como executar localmente

1. Baixe os três arquivos.
2. Mantenha-os na mesma pasta.
3. Abra `index.html` no navegador.

Não há dependências externas nem necessidade de instalar bibliotecas.

## Como publicar no GitHub Pages

1. Envie os três arquivos para a raiz do repositório.
2. No GitHub, acesse **Settings → Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch `main` e a pasta `/ (root)`.
5. Salve as alterações.

O arquivo inicial precisa manter o nome `index.html`.

## Estrutura narrativa

Cada partida tem 10 decisões, com três alternativas por decisão. A primeira escolha abre uma de duas histórias independentes:

- **Cidade para Todos:** mobilidade urbana, calçadas, travessias, transporte público, sinalização e manutenção.
- **Cultura para Todos:** teatro, elenco, ensaios, palco, recursos de comunicação, experiência do público e continuidade cultural.

Cada rota tem nove decisões próprias depois da bifurcação inicial. As escolhas alteram os indicadores de acessibilidade, participação e autonomia e influenciam o final.
